# 🎵 MeloVault v1.0.0

### Your Music. Your Vault.

MeloVault v1.0.0 is the first stable release of a modern, privacy-focused offline music player for Android.

MeloVault is designed to automatically discover, organize, and play music stored locally on your Android device, including music from internal storage and supported SD cards.

## ✨ Features

* 🎵 Automatic local music discovery
* 📁 Internal storage support
* 💾 SD card support
* 🔍 Search songs, artists, albums, and folders
* 🎧 Modern Now Playing interface
* ⏯️ Play, pause, previous, next, and seek controls
* 🔀 Shuffle playback
* 🔁 Repeat playback
* ❤️ Favorite songs
* 📂 Album and artist organization
* 📋 Playlist support
* 🕘 Recently played music
* 📱 Background playback
* 🌙 Modern dark interface
* ⚡ Fast offline playback
* 🔒 Local-first and privacy-focused
* 🚫 No account required for local music playback

## 🔐 Privacy

MeloVault is built around a local-first approach.

Your music library remains on your device. MeloVault does not require you to upload your personal music collection to a cloud server for local playback.

## 📱 Installation

### APK Installation

1. Download `MeloVault-v1.0.0.apk` from the **Assets** section below.
2. Open the APK on your Android device.
3. Allow installation from unknown sources if Android asks for permission.
4. Tap **Install**.
5. Open MeloVault.
6. Grant the required music/media access permission.
7. MeloVault will automatically scan your local music library.

### Build From Source

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/MeloVault.git
cd MeloVault
```

Open the project in Android Studio.

Allow Gradle to sync and download the required dependencies.

Connect an Android device with USB debugging enabled or use an Android emulator.

Select the `app` configuration and press **Run ▶**.
